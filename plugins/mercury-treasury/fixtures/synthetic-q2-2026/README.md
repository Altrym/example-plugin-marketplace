# Synthetic Q2 2026 Fixture

Synthetic demo data for Mercury Treasury Plugin.

Use these files to demonstrate Mercury PM - Banking / Cash & Treasury workflows without connecting to a live customer account. The values are invented and should not be used as benchmark or customer evidence.

## Versioned fixture sets

- `v0.1.0/`: baseline plugin behavior with more manual review and slower exception resolution.
- `v0.2.0/`: improved plugin behavior with richer rules, lower review volume, and cleaner telemetry.

The CSV files at this directory root mirror `v0.2.0/` so the default demo path uses the latest fixture set.

See `comparison.md` and `analytics/version-comparison.json` for side-by-side deltas.
