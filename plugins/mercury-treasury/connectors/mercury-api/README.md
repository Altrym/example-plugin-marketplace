# mercury-api

Connector placeholder for Mercury Treasury Plugin.

This directory documents the component declared in `telvine.plugin.json`. It does not contain live credentials or a runnable connector. For demos, load `../fixtures/synthetic-q2-2026/` instead.

Telemetry should emit `plugin.component.invoked` for safe metadata only: component type, component name, operation, duration, outcome, and counts. Never emit connector payloads.
