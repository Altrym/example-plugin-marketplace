# Synthetic Q2 2026 Fixture

Synthetic demo data for Xero Expensing Plugin.

Use these files to demonstrate Xero expense review workflows without connecting to a live customer account. The values are invented and should not be used as benchmark or customer evidence.

## Files

- `expense_claims.csv`: synthetic claims, categories, amounts, receipt state, and exception hints.
- `policy_rules.csv`: simplified policy thresholds and review rules.
- `reimbursements.csv`: synthetic reimbursement queue and payment readiness.

The default fixture set represents `v0.1.0` of the plugin.
