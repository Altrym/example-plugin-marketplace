# Tide Synthetic Q2 2026 Fixtures

Latest synthetic fixture snapshot for Tide Cashflow Ops. The root CSVs mirror `v0.2.0`.

Files:

- `accounts.csv`: SME account balances, available cash, low-balance thresholds, and projected 30-day balance.
- `cash_movements.csv`: synthetic inflows and outflows with category confidence.
- `invoices.csv`: invoice ageing and collection risk metadata.
- `cashflow_exceptions.csv`: ranked review exceptions and recommended actions.
