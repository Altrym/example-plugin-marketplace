# tide-open-banking Reference

Tide publishes Open Banking APIs through its developer portal. These are designed for regulated third-party providers using Open Banking flows, not for a normal Tide member looking for an in-app API key.

## Practical Use

- Use the browser workflow for direct user testing.
- Use Open Banking only if the implementer has the required provider registration, consent flow, and production or sandbox access.
- Treat this directory as a reference component, not an active connector fixture.

## Safety

Do not store or emit live account payloads, consent artifacts, access tokens, bank details, customer identities, prompts, tool arguments, screenshots, or model outputs in Telvine analytics.
